# Cassius the Skald

He can be found at the Den of the Seven Vales inn, in Waukeen's Promenade.

**Features:**
- Ability scores: STR 16, DEX 17, CON 13, INT 16, WIS 9, CHA 15.
- He has almost no dialogue, apart from a few banters.
- He has custom selection and action sounds (when you click on him, place him in the first party slot, etc.).
- He comes with 2 minor personal magical items.
